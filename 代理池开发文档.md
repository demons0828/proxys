# 代理池系统开发文档

## 1. 项目概述

### 1.1 项目目标
开发一个高性能的代理池系统，支持多种代理类型（HTTP、HTTPS、SOCKS5、SOCKS4），具备自动获取、验证、测速和管理功能。

### 1.2 主要功能
- 支持多种代理协议：HTTP、HTTPS、SOCKS5、SOCKS4
- 自动获取代理列表
- 代理IP地理位置信息补充
- 批量异步测速功能
- 持久化存储
- RESTful API接口
- 定时任务自动更新

## 2. 技术架构

### 2.1 技术栈
- **Web框架**: FastAPI
- **数据库**: SQLite
- **异步处理**: asyncio, aiohttp
- **IP地理位置**: qqwry.ipdb
- **任务调度**: APScheduler
- **数据验证**: Pydantic

## 3. 数据库设计

### 3.1 代理信息表 (proxies)
```sql
CREATE TABLE proxies (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    protocol TEXT NOT NULL,           -- HTTP/HTTPS/SOCKS5/SOCKS4
    host TEXT NOT NULL,               -- IP地址
    port INTEGER NOT NULL,            -- 端口
    username TEXT,                    -- 用户名（可选）
    password TEXT,                    -- 密码（可选）
    country TEXT,                     -- 国家
    region TEXT,                      -- 地区
    city TEXT,                        -- 城市
    isp TEXT,                         -- 运营商
    response_time REAL,               -- 响应时间（ms）
    success_rate REAL,                -- 成功率
    last_check TIMESTAMP,             -- 最后检查时间
    status TEXT DEFAULT 'active',     -- 状态：active/inactive/testing
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(protocol, host, port)
);
```

### 3.2 测试记录表 (test_records)
```sql
CREATE TABLE test_records (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    proxy_id INTEGER,
    target_url TEXT,
    response_time REAL,
    status_code INTEGER,
    success BOOLEAN,
    error_message TEXT,
    tested_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (proxy_id) REFERENCES proxies (id)
);
```

## 4. 核心模块设计

### 4.1 代理获取模块 (ProxyFetcher)
```python
class ProxyFetcher:
    async def fetch_http_proxies() -> List[ProxyInfo]
    async def fetch_https_proxies() -> List[ProxyInfo]
    async def fetch_socks5_proxies() -> List[ProxyInfo]
    async def parse_proxy_list(content: str) -> List[ProxyInfo]
```

### 4.2 代理验证模块 (ProxyValidator)
```python
class ProxyValidator:
    async def validate_proxy(proxy: ProxyInfo, target_url: str) -> TestResult
    async def batch_validate(proxies: List[ProxyInfo]) -> List[TestResult]
    async def get_location_info(ip: str) -> LocationInfo
```

### 4.3 数据库管理模块 (DatabaseManager)
```python
class DatabaseManager:
    async def save_proxy(proxy: ProxyInfo) -> None
    async def get_proxies(protocol: str, status: str) -> List[ProxyInfo]
    async def update_proxy_status(proxy_id: int, status: dict) -> None
    async def get_proxy_statistics() -> dict
```

### 4.4 任务调度模块 (TaskScheduler)
```python
class TaskScheduler:
    async def schedule_proxy_update() -> None
    async def schedule_proxy_validation() -> None
    async def schedule_location_update() -> None
```

## 5. API接口设计

### 5.1 获取代理接口
```
GET /api/proxies
Query Parameters:
- protocol: HTTP/HTTPS/SOCKS5/SOCKS4
- country: 国家筛选
- min_speed: 最小速度要求
- limit: 返回数量限制
```

### 5.2 代理状态接口
```
GET /api/proxies/{proxy_id}/status
```

### 5.3 添加代理接口
```
POST /api/proxies
Body: {
    "protocol": "HTTP",
    "host": "1.2.3.4",
    "port": 8080
}
```

### 5.4 统计信息接口
```
GET /api/statistics
```

### 5.5 手动更新接口
```
POST /api/update
Body: {
    "action": "fetch_new" | "validate_existing" | "update_location"
}
```
